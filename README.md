# Image & Video Processing Helper

A practical skill for media processing — image manipulation, video transcoding, computer vision, and metadata extraction.

## Installation

- **Cursor:** Place `SKILL.md` in `.cursor/skills/image-video-helper/SKILL.md`
- **Claude Code:** Add `SKILL.md` to `.claude/skills/` directory

## What it does

Guides AI agents to write better media processing code by:
- Suggesting appropriate packages for image/video operations
- Providing patterns for transcoding and optimization
- Including computer vision and OCR best practices
